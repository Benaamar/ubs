# UBS Banking Management System

Système de gestion bancaire UBS - Application complète avec frontend React et backend Node.js.

## 🚀 Déploiement

- **Frontend** : Déployé sur Vercel
- **Backend** : Déployé sur Render/Cyclic/Koyeb
- **Base de données** : MongoDB Atlas

## 📱 Installation sur iPhone

Voir le guide `INSTALLATION_IPHONE.md` pour installer l'application comme PWA sur iPhone.

## 🔧 Configuration

Voir les guides de configuration dans le dossier racine pour :
- Configuration du backend
- Configuration MongoDB
- Déploiement sur différentes plateformes

## ✨ Fonctionnalités

- Gestion des clients
- Opérations bancaires (dépôts, retraits, virements)
- Virements instantanés (max 20k CHF) ou en 2/3 jours
- Historique des opérations
- Interface PWA pour iPhone
